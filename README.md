THE UPHILL VOICE — WEBSITE / PWA PROTOTYPE

Files
- index.html: responsive website prototype, with embedded logo and CSS/JavaScript.

How to preview
1. Open index.html in a modern browser.
2. Use Home, Feature Stories, and Editorial Cartooning in the top navigation.
3. Click Admin CMS to add, edit, or delete placeholder stories and cartoons.

Important limitations
- This is a front-end prototype. CMS edits are stored in localStorage in the current browser/device only.
- There is no login, server database, multi-user publishing, image upload, or production hosting configured.
- The illustrations, article copy, author names, and dates are placeholders. Replace them with school-approved content.
- Google Fonts requires an internet connection; a sans-serif fallback is included.

For a live school publication, connect the interface to a secure backend/CMS, set editor permissions, and configure hosting and a domain. No payment features are included.
